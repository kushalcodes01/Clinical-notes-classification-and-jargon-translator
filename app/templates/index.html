          📐 Prompt Engineering Architecture & Methodology

          The RCTCO Framework

          Role (R): Board-certified patient health literacy nurse educator. Primes empathy and non-technical language.
          Context (C): Anxious patient reading clinical documentation; target 6th–8th grade reading level, short sentences.
          Task (T): Distinct prompts for Summarisation, Jargon Translation, and JSON Entity Extraction.
          Constraints (C): Strict zero-extrapolation guardrail, no unsolicited medical advice, explicit flagging of missing data.
          Output Format (O): Valid markdown with standard headings and strict JSON schemas for machine parsing.

          Designed for BTech CS Prompt Engineering coursework presentation & viva defense.
